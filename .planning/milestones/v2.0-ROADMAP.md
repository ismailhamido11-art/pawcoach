# Milestone v2.0 — Cleanup Technique (Archived)

**Date:** 26 mars 2026
**Duration:** 1 session (~3h)
**Commits:** 12
**Files changed:** 64 (+682 / -442 lines)

## Accomplishments

1. **Error feedback** — 14 silent catch blocks now show French error messages to users via toast
2. **Leaflet lazy loading** — Map library (~150KB) no longer blocks initial app load
3. **Public dog profile** — Owner email + chip number displayed for lost dog QR code use case
4. **Home cache** — Stale-while-revalidate cache eliminates loading screen on return visits
5. **Dog switch safety** — Cache auto-invalidates when active dog changes
6. **Data layer** — 42 files migrated from 202 raw SDK calls to centralized src/api/entities.js
