# Requirements: PawCoach v10.0 — Archive

**Defined:** 2026-03-28
**Completed:** 2026-03-29
**Core Value:** Un proprietaire de chien peut suivre la sante, l'alimentation, l'activite et le bien-etre de son chien au quotidien, avec des donnees fiables et coherentes.

## v10.0 Requirements (all complete)

### Securite
- [x] **SEC-01**: Le secret HMAC diagnostic ne doit jamais avoir de fallback en dur dans le code source
- [x] **SEC-02**: Premium.jsx affiche les liens Privacy Policy et Terms dans le footer

### Business Model
- [x] **BIZ-01**: Un utilisateur free ne peut avoir qu'un seul chien — gate a la creation avec nudge Premium
- [x] **BIZ-02**: Un utilisateur premium peut avoir jusqu'a 3 chiens

### Architecture
- [x] **ARCH-01**: Les pages utilisent useDog() au lieu de Dog.filter() individuel (14 pages migrees)
- [x] **ARCH-02**: Les pages utilisent useAuth() au lieu de base44.auth.me() individuel
- [x] **ARCH-03**: DogContext charge les donnees une seule fois, partagees entre toutes les pages

### Qualite Code
- [x] **QUAL-01**: Le pattern de navigation par tabs est extrait dans un hook useTabNavigation reutilisable
- [x] **QUAL-02**: VERDICT_CONFIG est centralise dans un fichier unique (plus de duplication)
- [x] **QUAL-03**: Les .catch(() => {}) silencieux sont remplaces par un error handling visible

### Performance
- [x] **PERF-01**: Les pages avec listes utilisent useMemo pour les calculs derives
- [x] **PERF-02**: Home charge les donnees above-the-fold en priorite avant le reste
