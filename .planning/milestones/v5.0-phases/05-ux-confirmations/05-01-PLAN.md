# Phase 05 Plan 01 : UX Confirmations — Remplacement des window.confirm()

## Objectif

Remplacer les 6 occurrences de `window.confirm()` dans la codebase par le composant `AlertDialog` de shadcn/ui pour une UX cohérente, accessible et visuellement soignee.

## Contexte

Le composant `AlertDialog` est deja disponible dans `src/components/ui/alert-dialog.jsx`. Il suffit de l'importer et d'appliquer le pattern standard dans les 3 fichiers concernes.

Les fichiers cibles :
- `src/components/activite/AITrainingProgram.jsx` (1 window.confirm — abandon programme)
- `src/components/nutrition/NutritionMealPlan.jsx` (2 window.confirm — delete plan, replace plan)
- `src/pages/Library.jsx` (3 window.confirm — delete bookmark, delete nutrition plan, delete scan)

## Taches

### Task 1 — AITrainingProgram.jsx
type: auto

Remplacer le `window.confirm` dans `startNewProgram` (ligne ~627) par un `AlertDialog`.

Ajouter :
- Import AlertDialog components
- State `confirmDialog`
- Modifier `startNewProgram` pour appeler `setConfirmDialog` au lieu de `window.confirm`
- Rendre le composant AlertDialog en fin de JSX

Texte : titre "Abandonner le programme ?" / description "Tu es au jour X/Y. Cette action est irreversible."
