# Phase 01 Plan 01 : Security — Ownership Checks & Data Exposure

## Objective

Corriger 3 failles de securite dans le backend et le frontend PawCoach :
- SEC-01 : deux fonctions backend ne verifient pas que le dogId appartient au user authentifie
- SEC-02 : la page publique DogPublicProfile expose des donnees privees (notes, medications, visites veto)
- SEC-03 : pawcoachChat fetche des quantites illimitees de records, ouvrant un vecteur d'abus de contexte

## Context

- Backend Deno sur Base44, SDK `@base44/sdk@0.8.20`
- Frontend React (JSX), pas de TypeScript
- Workflow : Git push → Base44 sync → 0 credit

## Tasks

### Task 1 — SEC-01 : generateTrainingProgram ownership check

**File** : `base44/functions/generateTrainingProgram/entry.ts`

**Problem** : Le dog est fetche via `asServiceRole` (bypass des ACL Base44) mais sans verifier que `dog.owner === user.email`. Un user malveillant peut generer un programme pour un chien qui ne lui appartient pas.

**Fix** : Apres le fetch du dog (ligne ~40), ajouter :
```ts
if (!dog || dog.owner !== user.email) return Response.json({ error: 'Forbidden' }, { status: 403 });
```

### Task 2 — SEC-01 : analyzeGrowthPhoto ownership check

**File** : `base44/functions/analyzeGrowthPhoto/entry.ts`

**Problem** : Pas de fetch du dog du tout — le dogId est utilise directement pour associer l'analyse photo sans verifier la propriete.

**Fix** : Ajouter un fetch + check ownership avant le traitement :
```ts
const dogs = await base44.asServiceRole.entities.Dog.filter({ id: dogId });
const dog = dogs?.[0];
if (!dog || dog.owner !== user.email) return Response.json({ error: 'Forbidden' }, { status: 403 });
```

### Task 3 — SEC-02 : DogPublicProfile filtrage des records

**File** : `src/pages/DogPublicProfile.jsx`

**Problem** : La section "Historique medical" affichait potentiellement notes, medications et visites veto. Les stats rapides exposaient les compteurs de visites veto et medications.

**Note** : Le filtre `r.type === 'vaccine' || r.type === 'weight'` dans la liste des records etait deja en place (ligne 292). Seules les stats rapides etaient a corriger.

**Fix** :
- Stats pills : remplacer `vetVisits.length` et `meds.length` par `weights.length` et le nombre de vaccins a jour
- Retirer les imports inutilises (Stethoscope, Pill, Loader2)

### Task 4 — SEC-03 : pawcoachChat entity query caps

**File** : `base44/functions/pawcoachChat/entry.ts`

**Problem** : Les 12 entites sont fetchees sans limite. Un chien avec des annees de donnees peut generer un contexte LLM enorme (couts + risque de troncature/injection).

**Fix** : Apres le `Promise.all`, ajouter un bloc de capping avant la construction du "DOG MEMORY" :
- `checkins` : fenetre 90 jours
- `dailyLogs` : fenetre 60 jours
- `foodScans` : 30 plus recents
- `healthRecords` : 20 plus recents
- Toutes les sections de memoire utilisent les arrays cappees
