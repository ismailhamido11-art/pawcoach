# Requirements: PawCoach v11.0

**Defined:** 2026-03-29
**Core Value:** L'app doit RESSEMBLER a une app premium — le design est la premiere impression.

## v11.0 Requirements

### Visual Polish

- [ ] **VIS-01**: Maximum 3 font-weights utilises dans l'app (400, 600, 700)
- [ ] **VIS-02**: Headers gradient compacts — pb max 5, pas de pb-8/pb-10
- [ ] **VIS-03**: Profile nom d'utilisateur jamais tronque sur mobile 375px
- [ ] **VIS-04**: Cards Home unifiees — 1 seul style de card (sauf CTA principal)

### Home Redesign

- [ ] **HOME-01**: 1 focal point clair par viewport (pas 6 CTAs concurrents)
- [ ] **HOME-02**: Above-fold = briefing + check-in uniquement, reste en scroll
- [ ] **HOME-03**: Progressive disclosure — contenu secondaire apres le fold
- [ ] **HOME-04**: Score art-direction Home >= 8.5/10

### Quality Gate

- [ ] **QUAL-01**: Score art-direction global >= 9.0/10
- [ ] **QUAL-02**: AI Slop detector 0/15 flags (remplacer Storyset si necessaire)
- [ ] **QUAL-03**: Premium Feel checklist >= 18/20

## Out of Scope

| Feature | Reason |
|---------|--------|
| Illustrations custom | Necessaire pour 10/10 mais hors budget ce milestone |
| Shared element transitions | Complexite disproportionnee pour le gain |
| Dark mode toggle | Fonctionne via OS, pas prioritaire |
