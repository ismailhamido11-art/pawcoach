## Component Organization Pattern

Components are organized **by feature** (not by type):

```
src/components/
├── <feature>/          # All components for that feature
│   └── FeaturePart.jsx
├── ui/                 # Shared UI primitives (shadcn + custom)
└── <standalone>.jsx    # Global/layout-level components
```

This means:
- A page like `Sante.jsx` imports from `@/components/sante/` (sub-content) and `@/components/notebook/` (notebook UI)
- A page like `Training.jsx` imports from `@/components/training/` and `@/components/activite/`
- Global utilities like `BottomNav.jsx` live at the component root
