**Contexte technique :** Les tab bars utilisent `grid grid-cols-5` (Sante, Nutri) et `grid grid-cols-4` (Activite). Ce n'est pas un scroll horizontal — les tabs sont toutes visibles. Mais sur un iPhone SE (320px) ou un Android compact, les 5 tabs en grid peuvent être très serrées et le texte tronqué.

FIX-34 demande un "gradient edge" sur le côté droit pour indiquer qu'il y a plus de tabs. Puisque c'est une grille (pas un scroll), l'effet doit être légèrement différent : on ajoute un gradient subtil en overlay sur le côté droit du tab container pour créer une sensation de "débordement potentiel" même si tout est visible.

**Implémentation CSS-only (div absolue) :**

Pour chaque page (Sante, Nutri, Activite), wrapper le `<div className="grid grid-cols-X ...">` dans un `<div className="relative">` et ajouter un div gradient en superposition :

```jsx
<div className="relative">
  <div className="grid grid-cols-5 gap-1.5 mt-1">
    {TABS.map(...)}
  </div>
  {/* Gradient edge — indique la présence d'autres onglets sur petit écran */}
  <div
    className="absolute top-0 right-0 h-full w-12 pointer-events-none"
    style={{
      background: "linear-gradient(to right, transparent, rgba(26,77,62,0.4))"
    }}
  />
</div>
```

Nota : le header de Sante/Nutri/Activite a un background gradient-primary (vert foncé). Le gradient de fade doit matcher cette couleur. Utiliser `rgba(26,77,62,0.4)` qui correspond à #1A4D3E (forest) avec opacité.

**Sante.jsx** : wrapper le `<div className="grid grid-cols-5 gap-1.5 mt-1">` en ajoutant `<div className="relative">` autour avec le div gradient.

**Nutri.jsx** : idem, `grid grid-cols-5`.

**Activite.jsx** : idem, `grid grid-cols-4`. Le gradient peut être légèrement plus petit (w-8) car 4 tabs sont moins serrées que 5.

**Note sur le design :** Ce gradient est subtil (opacity faible) pour ne pas masquer le tab actif si c'est le dernier. Tester mentalement : le tab "Veto" (5ème de Sante) et "Comparer" (5ème de Nutri) sont partiellement couverts par l'overlay. C'est le signal voulu (les derniers tabs sont moins visibles = incitation à scroller/explorer).

Si le tab actif est le dernier, le gradient peut le masquer partiellement. Pour éviter ça, une approche plus propre : afficher le gradient uniquement si le tab actif n'est PAS le dernier :
```jsx
{activeTab !== TABS[TABS.length - 1].id && (
  <div className="absolute top-0 right-0 h-full w-12 pointer-events-none" style={{background: "linear-gradient(to right, transparent, rgba(26,77,62,0.4))"}} />
)}
```

**Appliquer cette logique conditionnelle dans les 3 fichiers.**
