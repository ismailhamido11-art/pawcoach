# Phase 05 Plan 01: Accessibility — Icon-Only Buttons & Interactive Motion Elements

## Objective

Couvrir les deux exigences A11Y fondamentales :
- A11Y-01 : Tous les boutons icon-only ont un `aria-label` descriptif en français
- A11Y-02 : Les `motion.div` interactifs ont `tabIndex={0}` + `onKeyDown` Enter/Space

## Context

PawCoach est une PWA mobile-first. Les lecteurs d'écran (VoiceOver, TalkBack) ne peuvent
pas déduire l'action d'un bouton qui ne contient qu'une icône SVG sans texte ni aria-label.
De même, les `motion.div` avec `onClick` sont invisibles au clavier sans `tabIndex` + `role`.

### Task 2: Audit et correction — motion.div interactifs (A11Y-02)

Fichiers corrigés :

| Fichier | Élément | Correction |
|---------|---------|-----------|
| `pages/Training.jsx` | Carte guide comportement | `tabIndex={0}` + `role="button"` + `onKeyDown` |
| `components/tracker/NearbyParks.jsx` | Ligne parc (toggle expand) | `tabIndex={0}` + `role="button"` + `aria-expanded` + `onKeyDown` |
| `components/training/CelebrationScreen.jsx` | Backdrop dismissible | `tabIndex={0}` + `role="button"` + `aria-label="Continuer"` + `onKeyDown` |

Exclusions justifiées (motion.div avec onClick mais pas interactifs) :
- Overlays/backdrops (CombinedFAB, NotificationCenter, PremiumNudgeSheet, etc.) : fermeture via overlay est un pattern optionnel, le bouton Fermer explicite est toujours présent dans le dialog
- `motion.div` avec `onClick={e => e.stopPropagation()}` : pas d'action utilisateur, juste propagation stop
