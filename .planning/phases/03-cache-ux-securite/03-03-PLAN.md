**Contexte du probleme:**

Dans Training.jsx, le flow de completion d'exercice (dans le bloc `else` du try, lignes 256-268) :
```javascript
} else {
  const newP = await UserProgress.create({ ... });
  newProgresses = [...progresses.filter(p => !p._optimistic), newP];
  const newPoints = (user.points || 0) + 50;
  await base44.auth.updateMe({ points: newPoints });
  setUser(prev => ({ ...prev, points: newPoints }));
}
```

Si `UserProgress.create` reussit (ligne 257) mais `updateMe` echoue (ligne 267) :
- Le UserProgress existe en DB avec completed=true
- Les points ne sont PAS credites
- Le catch generique (ligne 275) rollback `progresses` state mais le record DB reste

**Fix:** Entourer le `updateMe` dans un try/catch interne. Si `updateMe` echoue, supprimer le UserProgress cree pour maintenir la coherence.

Le bloc `else` (lignes 256-268) devient :
```javascript
} else {
  const newP = await UserProgress.create({
    user_email: user.email,
    dog_id: dog.id,
    exercise_id: key,
    completed: true,
    completed_date: new Date().toISOString().split("T")[0],
  });
  // Replace the optimistic placeholder with the real record
  newProgresses = [...progresses.filter(p => !p._optimistic), newP];
  const newPoints = (user.points || 0) + 50;
  try {
    await base44.auth.updateMe({ points: newPoints });
    setUser(prev => ({ ...prev, points: newPoints }));
  } catch (pointsErr) {
    // UX-05: Rollback UserProgress if points update fails
    console.error("Training points update failed, rolling back UserProgress:", pointsErr);
    await UserProgress.delete(newP.id).catch(() => {});
    throw pointsErr; // Re-throw to hit the outer catch for UI rollback
  }
}
```

Le `throw pointsErr` fait remonter l'erreur au catch externe (ligne 275) qui rollback le state `progresses` et affiche le toast d'erreur. Ainsi la coherence est maintenue : pas de UserProgress orphelin sans points.

**IMPORTANT:** `UserProgress` est deja importe dans Training.jsx (verifier avec grep). `UserProgress.delete(id)` est disponible via le SDK Base44.
