# Phase 7 Plan 1 : Polish — Code Quality

## Objective
Corriger 6 issues de qualite de code identifiees post-v4.0 : consolider les useState de Home.jsx, ajouter un fallback a LottieAnimation, optimiser le filtre badgeUtils, remplacer les silent catches, ajouter des limits aux queries Library.jsx, et ajouter un TTL 30 jours a analytics.js.

## Tasks

### Task 1 — POLISH-02 : LottieAnimation fallback
Modifier `src/components/ui/LottieAnimation.jsx` pour afficher une icone PawPrint (Lucide) quand `failed=true` ou `!src`, au lieu de retourner null.

### Task 2 — POLISH-04 : Silent catches -> console.warn
Dans `src/components/activite/AITrainingProgram.jsx` et `src/components/CombinedFAB.jsx`, remplacer les `catch {}` vides par `catch (e) { console.warn("...", e?.message); }`.

### Task 3 — POLISH-03 : badgeUtils filter optimise
Dans `src/components/achievements/badgeUtils.jsx`, la fonction `checkPointMilestones` appelle `DogAchievement.filter({ dog_id: dogId })` pour recuperer tous les badges. Ajouter `badge_id` au filtre dans `unlockBadge` pour eviter les doublons — c'est deja fait ! Verifier et optimiser si besoin.

### Task 4 — POLISH-05 : Library query limits
Dans `src/pages/Library.jsx`, ajouter `, 100` (limit) aux appels `Bookmark.filter` et `NutritionPlan.filter`.

### Task 5 — POLISH-06 : Analytics TTL 30 jours
Dans `src/utils/analytics.js`, filtrer les events de plus de 30 jours lors de la lecture (`getEvents`), et s'assurer que chaque event a un timestamp.

### Task 6 — POLISH-01 : Home.jsx useState consolidation
Consolider les 24 useState de `src/pages/Home.jsx` en objets groupes `dogData` et `insights`.

## Success Criteria
- LottieAnimation affiche un fallback visible au lieu de null
- Aucun catch silent dans AITrainingProgram.jsx et CombinedFAB.jsx

- Home.jsx a des useState consolides en objets groupes (moins de 24 variables separees)
